# Shader Wallpapers — 10 sfondi animati interattivi

Ogni file è uno sfondo a sé stante, a schermo intero, che reagisce al mouse e ai click.

## File
1. `1 — Aurora Drift.html` — bande di luce iridescenti che si piegano verso il cursore
2. `2 — Plasma Orb.html` — orb di plasma agganciata al cursore, click = onda d'urto
3. `3 — Voronoi Neon.html` — celle al neon che si illuminano vicino al cursore
4. `4 — Singularity.html` — campo stellare deformato gravitazionalmente, click = buco nero
5. `5 — Liquid Chrome.html` — superficie metallica iridescente
6. `6 — Caustic Waters.html` — luce subacquea che balla, click = onde
7. `7 — Ferro Spikes.html` — fluido magnetico con spuntoni che puntano al cursore
8. `8 — Truchet Maze.html` — pattern geometrico di archi che si addensano
9. `9 — Lava Lamp.html` — metaballs caldi che si fondono col cursore
10. `10 — Tunnel Vortex.html` — tunnel infinito che sterza col mouse

## Come usarli come sfondo animato sul desktop

**Windows** — installa `Lively Wallpaper` (gratis, Microsoft Store):
Lively → "+" → "Browse" → seleziona un .html → diventa sfondo animato.

**macOS** — installa `Plash` (gratis, Mac App Store):
Plash → "Add Website" → file .html → si attiva come sfondo desktop.

**In alternativa** — aprili in Chrome/Firefox a schermo intero (F11) come screensaver interattivo.

## Per iPhone

iOS non supporta HTML come wallpaper. Usa `Wallpaper Recorder.html` per registrare ognuno come video MP4, poi:
1. AirDrop il video sull'iPhone
2. Apri **intoLive** (App Store, gratis) → importa → "Make Live Photo"
3. Lock Screen → tieni premuto → "+" → Foto → Live Photos → scegli quella

## Note tecniche
- Funzionano offline, nessuna dipendenza esterna.
- Richiedono WebGL (qualunque GPU degli ultimi 10 anni).
